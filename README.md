YOLOv13-N-HRNet-DCVN-for-Fall-Detection官方 PyTorch 实现 | 论文处于投刊阶段，标题：《基于上下文感知的深度学习大学生体育活动跌倒检测方法》提出融合 HRNet 高分辨率表征与多尺度上下文增强的实时检测模型 YOLOv13-N-HRNet-DCVN，实现大学体育课复杂场景下摔倒行为的高精度、实时检测，为校园体育安全监测提供边缘计算部署方案。1\. 研究背景与模型定位跌倒是全球性公共安全与健康威胁。在高校体育教学场景中，学生因激烈对抗、器械失误或场地湿滑引发的意外跌倒频繁发生。此类场景具有人群密集、运动幅度大、肢体遮挡严重、光照多变等特点，对检测系统的精度与实时性提出双重挑战。现有跌倒检测技术主要沿可穿戴传感、视觉感知与射频信号三条路径演进。可穿戴方法在传感器佩戴稳定性、剧烈运动适应性和长期舒适性方面面临瓶颈；射频方法在密集人群遮挡场景下精度受限；现有视觉方法所采用的逐级下采样骨干在严重遮挡和快速运动下易丢失空间细节。高分辨率表征与低计算开销之间的矛盾，仍制约边缘设备实现实时高精度检测。针对这一瓶颈，本文提出 YOLOv13-N-HRNet-DCVN 模型：以 YOLOv13-N 为基准框架，将骨干网络替换为并行高分辨率网络 HRNet，全程维护高分辨率特征图以保留空间细节；设计多尺度卷积注意力增强模块 DCVN，通过动态感受野与通道-空间注意力强化遮挡场景下的判别能力；在自建大学体育课跌倒数据集上，以 13.35M 参数量取得 99.82% mAP@50 与 2.0ms 推理速度，精度-速度权衡显著优于主流检测网络。2\. YOLOv13-N-HRNet-DCVN 核心创新点2.1 宽度扩展的 YOLOv13-N 基线将 YOLOv13-N 的宽度倍率由 0.25 提升至 0.5，对骨干网络与 Neck 中所有卷积模块的输出通道数进行等比翻倍：DSConv 模块：64/128/256 → 128/256/512A2C2f 模块：128/256 → 256/512HyperACE 模块：128 → 256参数量由 2.46M 升至 9.84M，计算量由 6.4 GFLOPS 升至 25.6 GFLOPS，显著增强模型的特征表达与抗过拟合能力。2.2 HRNet 高分辨率骨干网络定制化 HRNet 由初始下采样层、两级 HRModule 与输出适配层构成：每级 HRModule 含四条并行卷积分支（步长 1/2/4/8，对应 1/4 至 1/32 分辨率）；低分辨率分支经 1×1 卷积与最近邻上采样后，与首分支逐元素相加融合；两级级联持续增强多尺度语义，全程保持 1/4 高分辨率主分支，有效保留人体关节点位置与躯干倾角等关键空间细节。解决的问题：传统串行逐级下采样导致深层高分辨率空间细节严重衰减，制约对人体关节点与躯干倾角的细粒度感知。2.3 DCVN 上下文增强模块采用 "多尺度并行卷积 + 密集特征融合 + 通道注意力" 的轻量化优化思路：多尺度并行卷积：选用 3×3、5×5、7×7 三种卷积核构建并行分支，分别提取局部细节、中尺度肢体姿态与全局场景上下文特征；密集特征融合：多尺度输出与原始输入特征密集拼接，最大程度保留有效信息；通道注意力：自适应全局平均池化 + 轻量级全连接网络生成通道权重，强化摔倒关键特征，弱化操场地面、运动器材等背景干扰。DCVN 增加约 4.2M 参数，仅带来 0.2ms 额外延迟，实现精度与效率的协同优化。2.4 整体架构框架遵循 "输入预处理 → 高分辨率特征提取 → 多尺度上下文增强 → 双向特征融合 → 多尺度检测输出" 的全流程逻辑，通过 HRNet 保障空间定位精度、DCVN 强化语义判别能力、颈部精简设计提升推理效率，实现检测精度与实时性的协同优化。3\. 实验数据集3.1 自建数据集概况本研究构建的摔倒检测数据集来源于智能手机拍摄的运动场景视频，涵盖模拟与真实环境下的人体活动状态。数据采集于河南省多所高校，采用统一型号智能手机（Vivo S16e，5000 640×640，若原始图像分辨率过低（< 256×256），可能导致远距离小目标特征丢失，建议输入图像分辨率 ≥ 640×640；CUDA 版本问题：若安装 PyTorch 时出现 CUDA 不兼容，可替换为 CPU 版本（需将所有脚本的 --device 改为 cpu），但训练效率会大幅下降；田间场景适配：若用于实际校园体育场景，建议先通过 dataset/data\_loader.py 中的数据增强模块扩充数据集，提升模型对复杂光照、遮挡环境的适应能力；极端天气适配：当前模型未充分考虑雾天、暴雨等极端天气条件下的性能衰减，实际部署时建议结合图像去雾/去雨预处理模块。9\. 引用与联系方式9.1 引用方式论文处于投刊阶段，正式发表后将更新 BibTeX
